## 4. 工程架构

```
WenShuWriting/
├── app/src/main/java/com/wenshu/writing/
│   ├── MainActivity.kt                  # 单 Activity，承载 Compose
│   ├── WenShuApplication.kt             # 创建 AppContainer
│   ├── di/AppContainer.kt               # 依赖装配入口
│   ├── domain/model/Models.kt           # 领域模型、主题、AI 配置、字数统计
│   ├── data/
│   │   ├── local/AppDatabase.kt         # Room 数据库
│   │   ├── local/dao/                   # Novel / Chapter / Library / Settings DAO
│   │   ├── local/entity/                # Room 实体与模型映射
│   │   ├── remote/AiClient.kt           # OpenAI 兼容 Chat Completions 客户端
│   │   └── repository/                  # 书稿、设定库、偏好设置仓库
│   ├── feature/
│   │   ├── works/                       # 书稿列表、章节列表及 ViewModel
│   │   ├── editor/                      # 章节编辑器及 ViewModel
│   │   ├── library/                     # 设定库及 ViewModel
│   │   ├── ai/                          # AI 对话及 ViewModel
│   │   └── settings/                    # 设置及 ViewModel
│   └── ui/
│       ├── theme/                       # 墨蓝 + 暖纸色配色、深浅色主题
│       ├── navigation/                  # 路由、底部导航、NavHost
│       ├── components/                  # 空状态、删除确认、封面占位等复用组件
│       └── util/                        # 时间与字数格式化
├── gradle/libs.versions.toml            # 版本目录
├── app/schemas/                         # Room 导出的 schema（1.json）
└── build.gradle.kts / settings.gradle.kts / gradle.properties
```

分层原则：`feature` 只依赖仓库与领域模型，页面不直接访问 DAO；网络与数据库细节收敛在 `data` 层；依赖装配集中在 `AppContainer`。

## 5. 功能实现

### 书稿 Tab

- 新建小说：填写名称与简介，创建成功后直接进入章节列表。
- 书稿列表：按最近更新时间排序，展示简介与更新时间，可删除作品（外键级联删除章节）。
- 章节列表：显示章节序号、标题、字数、更新时间；可新建章节（标题留空自动命名为「第 N 章」），可删除章节。
- 章节编辑器：
  - 标题与正文均可编辑，支持大文本，输入区内部滚动。
  - 字数统计按“非空白字符”计数，符合中文写作习惯。
  - 输入停止 1.5 秒后自动保存；点击保存或返回时立即保存，避免内容丢失。
  - 保存写入 Room，同时更新作品更新时间。

### 设定库 Tab

- 「人物卡」「世界观」两个页签。
- 人物卡字段：姓名、身份/定位、性格背景描述。
- 世界观字段：分类（地理/势力/规则等）、标题、内容。
- 支持新建、编辑、删除，全部持久化到本机 Room 数据库。

### AI 对话 Tab

- API 配置面板：OpenAI 兼容 API 地址、API Key（密文显示/可切换）、模型选择（预置常用模型，也支持直接输入自定义模型）。配置写入本机数据库，下次启动自动读取。
- 请求方式：`POST {baseUrl}/chat/completions`，非流式，Bearer 鉴权，内置写作 System Prompt。
- 对话展示：用户/助手气泡，错误以独立错误气泡展示；生成中显示等待状态；可清空对话。
- 插入章节：选择“小说 → 章节”作为插入目标，每条 AI 回复下方可点击「插入章节」，内容追加到章节末尾（自动补空行）。
- 对话上下文保存在内存中（当前骨架不改写章节，仅由用户手动插入）。

### 设置 Tab

- 主题三档：跟随系统 / 浅色 / 深色，选择后写入本机并即时生效。
- 展示 AI 配置入口说明、本地存储说明与版本信息。
- 状态栏、导航栏图标明暗随主题切换。

### 其他

- 底部导航四个 Tab：书稿、设定库、AI 对话、设置。
- 详情页（章节列表、编辑器）自动隐藏底部导航，支持系统返回键。
- 自定义启动图标：自适应图标 + 安卓 7.0 兼容 PNG 图标。

## 8. 已知边界与商用迭代建议

1. API Key 目前以明文存入 Room。商用前建议迁移到 Android Keystore / EncryptedSharedPreferences，并增加 HTTPS 强制校验。
2. AI 对话只支持非流式返回，对话记录不持久化；可扩展 SSE 流式输出、会话历史与 Prompt 模板。
3. 书稿目前仅支持单层章节，无分卷、排序拖拽、导入导出与全文搜索；可在现有 `chapters.orderIndex` 基础上扩展分卷编号。
4. 主题目前是模式切换，配色集中在 `ui/theme/Color.kt`；后续可增加自定义主题色与字体。
5. 单模块工程便于快速迭代；功能增多后可按 `:core:data`、`:core:domain`、`:feature:*` 拆模块，`AppContainer` 可平滑替换为 Hilt。
6. `AiClient` 与仓库均为独立类，可抽出接口以支持多模型、多供应商、Mock 测试与依赖注入。
7. `gradle.properties` 的内存参数针对 4 GB 构建容器调低；本地开发可按机器配置适当提高。
