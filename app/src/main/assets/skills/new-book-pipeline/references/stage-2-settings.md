# 阶段 2 · 生成新书基础设定

## 任务

基于作者提供的新书信息，生成一套可直接落库的基础设定：

- 世界观完整规则：力量体系 / 能力边界 / 势力格局 / 世界运行规则 / 主要舞台
- 全套人物卡：主角、主要对手、关键配角，每人包含姓名、身份定位、性格、背景与人物关系
- 金手指体系：来源、能力、成长路径、代价与限制

## 质量要求

- 所有设定必须服务于「核心创意」与「目标赛道」，不要堆砌无关名词。
- 能力体系必须自洽：等级清晰、升级条件明确、代价不可为零。
- 人物动机与冲突要能直接支撑后续剧情。

## 输出格式（只输出 JSON，不要解释）

```json
{
  "worldSettings": [
    {"category": "力量体系", "title": "体系名称", "content": "完整规则说明"}
  ],
  "characters": [
    {"name": "姓名", "role": "身份定位", "description": "性格、背景、关系、动机"}
  ],
  "goldenFinger": {
    "title": "金手指名称",
    "content": "来源、能力、成长路径、代价与限制"
  }
}
```
