# 阶段 3 · 生成分级大纲

## 前置约束

必须先阅读本书已入库的全部人物卡与世界观设定，任何大纲情节都不得与其冲突。

## 任务

1. 全书总纲：主线目标、核心矛盾、分卷节奏、高潮分布、结局走向。
2. 前期详细细纲：至少 10 章，每章写明关键事件、冲突升级与信息释放。

## 要求

- 遵循目标赛道的节奏规则：前三章必须完成主角处境、核心冲突与首个爽点。
- 每章至少推进一个信息增量，禁止连续两章原地踏步。
- 细纲必须能直接转换为章节任务卡。

## 输出格式（只输出 JSON，不要解释）

```json
{
  "overall": "全书总纲全文",
  "details": [
    {"title": "第1章 章节名", "content": "本章关键事件、冲突、爽点与钩子"}
  ]
}
```
