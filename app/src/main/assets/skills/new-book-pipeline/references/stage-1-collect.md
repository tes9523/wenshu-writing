# 阶段 1 · 信息采集

## 目标
从作者一句话想法中，采集新书立项的六项核心信息。

## 必须采集的字段
1. 题材：玄幻 / 仙侠 / 都市 / 科幻 / 历史 / 游戏 / 悬疑 / 其他
2. 卖点：一句话概括本书最吸引读者的核心爽点或差异化设定
3. 目标赛道：男频 / 女频 / 泛读者，并说明目标读者画像
4. 核心创意：故事的核心脑洞或钩子
5. 风格偏好：轻松 / 严肃 / 热血 / 虐心 / 沙雕 / 其他

## 交互要求
- 一次性向作者提问，列出六个字段，请作者逐项填写
- 作者回答后，整理成结构化的 NewBookInfo
- 调用 info_collect 工具落库，然后暂停等待确认
- 缺少任何一项都要追问，不得跳阶段

## 输出
只输出结构化 JSON，不要附加解释。
