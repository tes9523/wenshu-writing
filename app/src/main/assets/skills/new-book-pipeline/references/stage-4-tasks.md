# 阶段 4 · 生成章节任务卡

## 任务

基于全书总纲与前期细纲，为每一章产出标准化任务单，字段必须完整：

- 本章目标：主角在本章要完成的具体目标
- 核心冲突：谁阻止、阻力是什么、失败代价
- 信息增量：读者或主角本章新获得的关键信息
- 爽点设计：情绪释放点，必须具体到情节动作
- 章末钩子：让读者点下一章的理由

## 要求

- 任务卡与细纲逐章对应，不得增删章节顺序。
- 每章至少一个明确冲突与一个具体爽点，禁止「打脸」「装逼」这类空泛描述。
- 钩子必须落在未解问题、突发变故或身份反转上。

## 输出格式（只输出 JSON，不要解释）

```json
{
  "tasks": [
    {
      "title": "第1章 章节名",
      "goal": "本章目标",
      "conflict": "核心冲突",
      "infoIncrement": "信息增量",
      "payoff": "爽点设计",
      "hook": "章末钩子"
    }
  ]
}
```
