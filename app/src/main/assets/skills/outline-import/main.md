# 大纲成书

当用户提供的是一份**完整的小说大纲**（包含明确书名，以及故事主线 / 分卷 / 章节规划等结构）时，你需要：

1. 从大纲中提取最合适的书名；
2. 正常给出简短确认或建议，不要复述整份大纲；
3. 在回复的**最后单独一行**输出建档标记：

```
<<WENSHU_NEW_BOOK>>{"title":"提取到的书名"}
```

规则：

- 标记只能出现一次，且必须是回复的最后一行；
- `title` 使用大纲中出现的正式书名，去掉《》与多余空格；
- 如果无法确定书名，或用户输入不构成有效大纲，则**不要输出标记**，正常文字回复；
- 不要输出其他 JSON、不要伪造 bookId 或章节数据，书稿创建由 App 完成；
- 创建完成后 App 会自动把用户提供的大纲正文写入该书稿的大纲区域，并绑定该书稿的 bookId。

## 边界

- 本技能只负责「已有大纲 → 生成书稿载体」；
- 从零立项、分阶段生成设定与正文请使用【开启新书】流水线，二者互不替代。
