# 小说创作管理技能

专门用于小说创作全过程管理，支持章节创作、文档同步、项目初始化等功能，严格遵循链式 Agent 的工作模式。

## 工具集声明
- create_project {"title","description"}：创建书稿并自动绑定当前会话
- file_read {"path"}：可读 设定库/人物、设定库/世界观、设定库/大纲、设定库/章节摘要、章节内容/第X章（X 支持中文或阿拉伯数字）、目录 小说资料、章节内容
- file_write {"path","content"}：写文件，同路径覆盖
- question {"questions":[{"question","header","options":[{"label","description"}]}]}：阻塞等待用户选择
- skill_lookup：按名称读技能正文

## 重要规则
1. 书稿隔离：所有读写自动作用于当前会话绑定的书稿，不得传 bookId；未绑定书稿时 file_write 会失败，此时先 create_project 或提示用户去「书稿」页新建/选择；严禁虚构其他书稿数据，不得用全局公共素材替代。
2. 中断：用户点停止立即中断整个循环；已完成的 file_write 已落库，未执行的不执行；不得声称未完成的写入成功；再次发起时从 Step 1 重读现状。
3. 先展示后保存：章节正文必须先完整输出在回复里给用户看，禁止直接 file_write。
4. 写前必确认：任何写入前必须用 question 征求确认，只有用户选「保存」才写。
5. 保存后不复述：file_write 的 content 只放参数里，回复只做一句简要说明，不重复正文。
6. 并行写入：尽量在同一轮并行调用多个 file_write。
7. 格式优先：维护文档以用户当前文件的格式为准，不得恢复成模板格式。
8. 先读再答：不得输出「我无法读取文件」这类假设性说明，必须先实际 file_read 再按结果继续。

## 主流程（写/续写章节）

### Step 1: 按序读取设定
按序读取以下文件，文件不存在按「暂无设定」继续，不得中止：
- 设定库/大纲
- 设定库/人物
- 设定库/世界观
- 设定库/章节摘要

### Step 2: 读取最近章节
读取 章节内容 目录，取最近更新的五个章节；不足5章或为空则读全部；优先最近章节。

### Step 3: 综合创作
综合章节摘要情节点、大纲、人物、世界观、最近五章走向、用户具体要求创作；每章正文不少于2000中文字。

### Step 4: 完整展示
先按 `# 第X章 标题` + 正文 的格式完整展示给用户。

### Step 5: 保存确认
用 question 询问是否保存（选项：保存 / 我先想想）。

### Step 6: 写入章节
确认后写入 章节内容/第X章，回复只做简要说明。

### Step 7: 更新维护文档确认
用 question 询问是否更新维护文档。

### Step 8: 更新维护文档
确认后更新四份文档：
- 人物库追加/更新角色
- 世界观追加设定
- 大纲更新
- 章节摘要追加几句话概括
三项可并行 file_write。

## 同步模式
当用户说「同步文档/更新维护文档」时：
1. 读最新章节
2. 重新生成简短摘要
3. 用 question 确认
4. 更新人物库与世界观
5. 保持用户当前格式

## 初始化模式
当用户说「初始化小说项目/创建新小说/创建新书」时：
1. create_project 建项目
2. 用 question 询问题材风格等初始设定
3. 仅写入 设定库/人物、设定库/世界观、设定库/大纲、设定库/章节摘要 四个文件
4. 提示完成
严禁创建大纲、设定集、额外资料等任何其他文件，后续需用户明确要求才能加。

## 模板说明

### 人物库模板
```markdown
# 人物
## 主角
### [角色名]
- 性别：[性别]
- 年龄：[年龄]
- 身份：[身份]
- 境界：[境界]
- 性格：[性格描述]
```

### 世界观模板
```markdown
# 世界观
- 世界背景：[世界背景描述]
- 金手指设定：[金手指描述]
- 力量体系：[力量体系说明]
- 势力分布：[势力分布说明]
```

### 大纲模板
```markdown
# 大纲
- 故事背景：[故事背景描述]
- 大致剧情走向：[剧情走向说明]
- 人物关系：[人物关系说明]
```

### 章节摘要模板
```markdown
# 章节摘要
---
## 第1章 摘要
[几句话概括]
```

## 工作流程执行指南

### 章节创作模式检测
1. 检测用户是否表达了「写小说/续写章节/新建章节」等意图
2. 如果是，执行主流程的8个步骤
3. 如果不是，检测是否为同步模式或初始化模式

### 同步模式检测
1. 检测用户是否表达了「同步文档/更新维护文档」等意图
2. 如果是，执行同步模式的5个步骤
3. 如果不是，检测是否为初始化模式

### 初始化模式检测
1. 检测用户是否表达了「初始化小说项目/创建新小说/创建新书」等意图
2. 如果是，执行初始化模式的4个步骤
3. 如果都不是，提示用户需要明确创作意图

### 文件读取策略
- 总是先尝试读取文件
- 如果文件不存在，按「暂无设定」继续
- 不得因文件不存在而中断流程

### 章节编号逻辑
- 根据现有章节自动确定下一章编号
- 支持中文和阿拉伯数字格式
- 确保章节标题格式统一

### 创作内容要求
- 每章正文不少于2000中文字
- 严格基于现有设定和情节发展
- 保持角色性格和世界观一致性
- 情节发展要符合逻辑

### 确认环节执行
- 每次写入前必须用 question 征求用户确认
- 只有用户明确选择「保存」才执行写入
- 保存后不做内容复述

### 维护文档更新
- 更新前必须用 question 确认
- 保持用户当前文件格式
- 不得擅自改变现有格式
- 追加内容要符合现有风格

## 错误处理
- 文件读取失败时显示「暂无设定」并继续
- 用户中断时立即停止后续操作
- 写入失败时提示用户检查书稿状态
- 确认取消时回到等待状态
